# Apple Platform 調査スキル

## 目的

Apple固有の技術判断を、古い慣習や第三者記事ではなく公式一次情報から行う。

## 手順

1. 問いを具体化する。
2. Apple Developer Documentationを検索する。
3. HIGに関連項目がある場合は確認する。
4. WWDCの近年セッション/Group Labを確認する。
5. API Availabilityと対象OSを確認する。
6. 事実と提案を分けてまとめる。

## 出力形式

- 問い
- 結論ではなく確認できた事実
- 公式URL
- 確認日
- 対象OS/API Availability
- プロジェクトへの適用候補
- 未確認事項
